2. Identificación del producto

Nombre del producto GuardianOS Audit
Versión cubierta 1.x (versión estable actual)
Descripción Plataforma de auditoría de ciberseguridad con análisis automatizado de dominios, infraestructura web y servidores Linux/Windows. Incluye motor de evaluación de 21 marcos normativos (ISO 27001, GDPR, ENS, NIS2, DORA, PCI DSS, NIST, CIS, SOC 2…), generación de informes PDF con cadena forense SHA-256 y certificados verificables con QR. Análisis IA (Claude) bajo demanda. Dashboard con sistema de señales (signal pills) por auditoría: delta de score, nuevos hallazgos, recuento de CVEs altos, porcentaje ENS, vencimiento SSL, grado TLS y detección de subdomain takeover. Sistema de webhooks con 5 eventos configurables: audit_failed, cve_alert, compliance_changed, member_invited y member_accepted.
Clasificación CRA Producto de categoría predeterminada (Clase I, Anexo III del Reglamento). No requiere evaluación por organismo notificado — se aplica procedimiento de autoevaluación.
Licencia AGPL-3.0 (código fuente disponible públicamente)
Registro propiedad intelectual Registro de Software — Propiedad Intelectual Junta de Andalucía · Registro nominativo OEPM

4. Verificación de requisitos esenciales — Anexo I, Parte I

Requisito esencial CRA Estado Mecanismo de cumplimiento
Sin vulnerabilidades explotables conocidas en la entrega CUMPLE Revisión de dependencias antes de cada release; sin CVEs activos conocidos
Configuración segura predeterminada CUMPLE Docker con red interna; HTTPS obligatorio; sin puertos innecesarios
Confidencialidad (datos en reposo y tránsito) CUMPLE TLS 1.3; bcrypt factor 12; API keys hasheadas SHA-256; sin texto plano
Integridad de datos y software CUMPLE JWT firmado; cadena forense SHA-256; queries parametrizadas
Disponibilidad y resiliencia básica PARCIAL Rate limiting nginx; sin mitigación DDoS volumétrico dedicado
Control de acceso — mínimo privilegio CUMPLE Multi-tenant; JWT por usuario; contenedores sin root
Minimización de superficie de ataque CUMPLE Solo 80/443 expuestos; red interna Docker privada
Política de divulgación de vulnerabilidades CUMPLE .well-known/security.txt publicado; PGP disponible; plazos definidos
Instrucciones de uso seguro CUMPLE Documentación técnica en guardianos.es/audit/security; guías de despliegue en guardianos.es/docs
Actualizaciones de seguridad durante el soporte CUMPLE Publicados en guardianos.es/audit/security; parches críticos ≤14 días
