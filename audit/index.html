Agentes Linux & Windows

Scripts Bash/PowerShell desplegables en cualquier servidor. Auditorías periódicas programadas con cron / Tarea Programada. Resultados enviados cifrados al dashboard propio.

Análisis IA Bajo Demanda

Claude (claude-sonnet) analiza el informe solo cuando lo solicitas. Explica riesgos en lenguaje ejecutivo, prioriza remediaciones y estima el impacto financiero. Cero tokens en auditorías base.

Privacy by Design

Credenciales never stored en BD, API keys hasheadas SHA-256, JWT autenticación, multi-tenant y código 100% auditable. Sin backdoors. AGPL-3.0.

Auditorías en Lote

Lanza hasta 20 auditorías en paralelo sobre múltiples dominios o IPs con un solo click. Estado en tiempo real por objetivo, informes individuales y listado persistente en base de datos — los lotes sobreviven reinicios del backend.

Auditorías Programadas

Automatiza auditorías periódicas (diarias, semanales, mensuales). Genera PDF + certificado automáticamente al completar, notifica por email y mantiene historial completo con enlace al último informe por objetivo.

Cómo funciona

De dominio a informe profesional en 10 minutos — con IA cuando la necesitas

1

Configura tu objetivo

Agentes para Linux y Windows

Despliega un agente ligero en tus servidores y automatiza auditorías periódicas con tu propio backend, base de datos y dashboard

Agente Linux

Script Bash autocontenido. Audita el sistema operativo, servicios activos, usuarios, permisos, paquetes desactualizados y configuración SSH. Programable con cron cada hora, día o semana.

  • Compatible con Debian, Ubuntu, RHEL, CentOS, Arch
  • Sin dependencias externas — solo bash + curl
  • Firma SHA-256 de cada envío
  • Integración con Wazuh / CEF / SIEM

Agente Windows

Script PowerShell firmado. Audita rol del servidor, políticas de grupo, actualizaciones pendientes, servicios críticos y configuración de firewall. Ejecutable como Tarea Programada.

  • Compatible con Windows Server 2016, 2019, 2022 y W10/11
  • Sin agente residente — ejecución puntual o periódica
  • Resultados cifrados con AES-256 antes del envío
  • Soporte GPO y entornos Active Directory

Backend + Dashboard + BD

Infraestructura propia desplegable en tu servidor. Los agentes reportan a tu instancia; ningún dato sale a servidores de terceros.

  • API REST con JWT y API keys hasheadas
  • Base de datos con histórico y comparativas entre auditorías
  • Dashboard web con score, hallazgos y tendencias
  • WebSocket para progreso en tiempo real

Preguntas frecuentes

Todo lo que necesitas saber antes de empezar

¿Necesito conocimientos técnicos para usar GuardianOS Audit?

No. El dashboard web guía paso a paso el proceso. Los informes incluyen un resumen ejecutivo en lenguaje claro. Para opciones avanzadas (SSH, agentes), ofrecemos soporte guiado.

¿Se envían mis datos a servidores externos?

No. Puedes desplegar GuardianOS Audit en tu propia infraestructura con Docker. En la versión cloud, los escaneos se ejecutan en instancias efímeras y los datos se eliminan tras generar el informe. Nunca almacenamos credenciales.

¿Puedo auditar sistemas de terceros?

Solo con autorización explícita por escrito del propietario. Incluimos una plantilla de autorización en docs/legal/. El uso no autorizado de herramientas de auditoría puede ser ilegal.

¿Qué diferencia hay entre la app GuardianOS y GuardianOS Audit?

GuardianOS (app móvil) es para auditorías personales de dispositivos Android. GuardianOS Audit es una plataforma profesional para evaluar infraestructuras web, dominios y servidores de organizaciones. Son complementarias.

¿El certificado caduca?

Sí, 30 días por diseño. La ciberseguridad es un proceso continuo. Al renovar la auditoría, se genera un nuevo certificado que encadena criptográficamente con el anterior (blockchain-lite), creando un historial verificable.

¿Cuándo se usa el análisis IA y cuánto consume?

El análisis IA con Claude es completamente opcional y bajo demanda. La auditoría técnica completa y el PDF se generan sin consumir ningún token. Solo activas el análisis IA en los informes que lo necesiten — desde el dashboard o via API. El coste en tokens se controla al 100% desde tu panel.

¿Puedo integrar GuardianOS Audit en mis procesos como MSP o consultora?

Sí. Disponemos de API REST completa (OpenAPI/Swagger) para lanzar auditorías, recibir PDFs, activar análisis IA y emitir certificados de forma programática. Ideal para MSPs que quieren automatizar auditorías recurrentes de sus clientes o consultoras que integran los informes en su flujo de entrega. Escríbenos para hablar de condiciones de volumen.
