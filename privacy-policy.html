2. Data Accessed by the App

GuardianOS Shield needs access to certain device information to provide effective parental control. All this information remains on your device.

📱 Device Information

  • Model and manufacturer (for service optimization)
  • Android version (feature compatibility)
  • Battery status (exclude from optimizations)

📦 Installed Applications List

  • Application names
  • Package names
  • Usage time per app (UsageStats)
  • Apps detected in foreground (for parental blocking)

🌐 Blocked DNS Queries

  • Domains blocked by filter (e.g., adult-site.com)
  • Date and time of access attempt
  • Block category (adult, social media, malware)
  • NOT stored: Page content, credentials, encrypted traffic

🔒 Parental Control Configuration

  • Parental PIN (encrypted with AndroidKeyStore)
  • Allowed usage schedules
  • Configured restriction level
  • Apps marked as sensitive by parents

3. What We Do NOT Do With Your Data

  • NO sending data to external servers (except DNS to CleanBrowsing)
  • NO selling information
  • NO sharing with third parties
  • NO inspecting HTTPS traffic content
  • NO location tracking
  • NO accessing messages, photos, or personal files

4. Data Storage

Data is stored locally:

  • Room Database: Blocked sites history, user profiles, configuration (stored in /data/data/com.guardianos.shield/databases/)
  • Encrypted DataStore: App configuration and service status
  • EncryptedSharedPreferences: Parental PIN hashed with SHA-256 and encrypted with AES256-GCM
  • Retention: DNS logs are automatically deleted after 30 days (configurable)

5. DNS Filtering with CleanBrowsing

What is CleanBrowsing?

CleanBrowsing is a public DNS service that filters inappropriate content. GuardianOS Shield redirects DNS queries to their servers (185.228.168.168) when VPN mode is active.

Data sent to CleanBrowsing:

  • Queried domain names (e.g., google.com, facebook.com)
  • Device IP address (temporary, to respond to the query)

CleanBrowsing Privacy Policy: https://cleanbrowsing.org/privacy

Important: CleanBrowsing CANNOT see the encrypted content of your HTTPS connections. It only sees domain names.

7. Requested Permissions

The app requests the following Android permissions:

🔍 QUERY_ALL_PACKAGES

Why? Allows listing all installed applications for parental control monitoring.

Justification: Essential for detecting and blocking sensitive apps according to parent/guardian configuration.

📊 PACKAGE_USAGE_STATS

Why? Allows detecting which app is in foreground and measuring usage times.

Justification: Necessary for applying usage schedules and blocking apps outside allowed hours.

🔒 BIND_VPN_SERVICE

Why? Allows creating a local VPN tunnel to intercept DNS queries.

Justification: This is the mechanism that enables DNS filtering without inspecting data traffic.

Clarification: The VPN is local, it does NOT redirect your traffic to remote servers. It only redirects DNS to CleanBrowsing.

🔔 POST_NOTIFICATIONS (Android 13+)

Why? Display notifications when a site or app is blocked.

🔋 REQUEST_IGNORE_BATTERY_OPTIMIZATIONS

Why? Prevent the system from killing monitoring services in the background.

Justification: Necessary for continuous protection without interruptions.
